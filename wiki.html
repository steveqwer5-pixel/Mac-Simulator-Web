1. 项目概述

Mac Simulator 是一款深度还原 macOS 系统外观与交互模式的模拟器。项目融合了全新的 Dynamic Island（灵动岛）、Spotlight 聚焦搜索、窗口管理器以及云端社区反馈模块。

核心技术栈：

HTML5 / CSS3 拟态玻璃（Glassmorphism）与动画过度 Vanilla JS 模块化原生交互逻辑 Supabase Backend-as-a-Service (BaaS) 云端存储与 OAuth 鉴权

2. 核心模块说明

2.1 Spotlight 聚焦搜索 (Spotlight)

提供系统级的全局快捷搜索框，支持系统快捷键唤醒。动态匹配应用图标、本地计算及快速跳转命令。

2.2 Dynamic Island (灵动岛 / WinIsland)

融合于顶部 Status Bar 的交互胶囊，具备以下状态分发机制：

  • Idle 状态： 隐匿或仅显示基本状态指示。
  • Expanded 展开态： 点击或触发系统通知（播放器控制、系统提醒、状态绑定成功等）时平滑展开。

2.3 窗口管理器 (Window Manager)

模拟 macOS 经典的红黄绿“三色粒”按钮：控制窗口最小化、全屏扩展以及销毁关闭，支持层级（zIndex）置顶与自由拖拽。

3. 系统交互与快捷键

快捷键组合 触发功能 作用模块
Cmd + Space / Ctrl + Space 唤醒 / 隐藏 Spotlight 搜索框 Spotlight 聚焦搜索
Esc 关闭当前处于顶层的浮层或弹窗 全局窗口控制

4. 留言反馈与特权体系

项目集成了在线留言反馈页面 feedback.html，与 GitHub OAuth 及 Supabase 数据库深度绑定。

4.1 权限等级机制

角色类型 鉴定标准 (UID) 留言操作权限
访客 (Guest) 未绑定 / 未登录 Session 仅查看他人留言，无法提交或删除
普通绑定用户 已完成 GitHub 绑定认证 可发布留言，且仅能删除自己发表的留言
系统大管理员 a36ece6a-25b8-4772-b404-4980a1958d5b 最高治理特权：可管理/删除全站任意留言

5. Supabase 数据库与安全策略

为了配合特权 UID 系统，Supabase comments 表需配置以下 RLS 安全规则：

-- 1. 数据表绑定与外键
create table if not exists comments (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  user_id uuid references auth.users(id),
  username text,
  avatar_url text,
  content text
);

-- 2. 特权删除策略 (包含管理员 UID 硬编码鉴权)
create policy "Allow user or admin delete" on comments 
for delete using (
  auth.uid() = user_id 
  or 
  auth.uid() = 'a36ece6a-25b8-4772-b404-4980a1958d5b'::uuid
);

6. 部署说明与配置

项目部署至生产服务器时，请确保配置满足以下依赖：

  • 站点重定向： 需在 Supabase Auth 控制台中将 https://msw.zapto.org/feedback.html 填入 Redirect URLs 白名单。
  • 资源路径： 确保背景 bg-canvas 与组件所需图标资源（favicon, Mac 窗口微粒）存放于根目录下。
