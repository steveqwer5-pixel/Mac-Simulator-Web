1. 项目简介

本项目为 Mac Simulator 网站的嵌入式留言与社区反馈模块。采用无服务器（Serverless / Pure Frontend）架构构建，前端无需自建后端 API 即可完成用户鉴权、数据持久化存储与权限隔离。

核心功能列表：

  • 身份认证 支持通过 GitHub OAuth 完成无密第三方绑定登录。
  • 数据交互 实时显示社区留言列表，支持文本防 XSS 转义提交。
  • 权限控制 支持普通用户删除本人发布的留言；指定系统管理员 UID 拥有最高治理权限（可清理任意留言）。

3. Supabase 数据库设计

项目在 Supabase 中使用 PostgreSQL 数据库，核心数据表为 comments。

字段名 (Column) 数据类型 (Type) 主键/外键 说明
id bigint / int8 PRIMARY KEY 留言唯一 ID，自增主键
created_at timestamptz - 留言创建时间（默认值为 now()）
user_id uuid FK -> auth.users.id 对应 Supabase 用户系统中唯一 UID
username text - 发帖人的 GitHub 用户名
avatar_url text - 发帖人的 GitHub 官方头像直链
content text - 留言的具体正文内容

4. 身份验证与权限控制

4.1 RLS (Row Level Security) 策略 SQL

在 Supabase SQL Editor 中运行以下命令，确保数据安全性：

-- 允许全员查询/读取留言
create policy "Allow public read" on comments for select using (true);

-- 允许已登录用户插入新留言
create policy "Allow authenticated insert" on comments for insert with check (auth.role() = 'authenticated');

-- 限制删除策略：仅限发布者本人 或 特权管理员 (指定 UID) 删除
create policy "Allow user or admin delete" on comments 
for delete using (
  auth.uid() = user_id 
  or 
  auth.uid() = 'a36ece6a-25b8-4772-b404-4980a1958d5b'::uuid
);

4.2 前端特权管理员鉴权逻辑

前端脚本中硬编码设置系统大管理员常量：

const ADMIN_UID = 'a36ece6a-25b8-4772-b404-4980a1958d5b';

// 判断逻辑：当前登录用户的 UID 等于 ADMIN_UID 时，拥有全局删除权限
const isAdmin = currentUser && currentUser.id === ADMIN_UID;
const canDelete = isAdmin || (currentUser && currentUser.id === item.user_id);

5. 关键环境变量配置

前端部署在生产环境（例如 https://msw.zapto.org/feedback.html）时，需确保以下三端参数配置完全一致：

  1. Supabase Authentication -> URL Configuration:
    • Site URL: https://msw.zapto.org
    • Redirect URLs: https://msw.zapto.org/feedback.html
  2. GitHub Developer Settings -> OAuth App:
    • Authorization callback URL: https://<你的项目ID>.supabase.co/auth/v1/callback
  3. 前端 JS 初始化参数：
    • SUPABASE_URL 与 SUPABASE_ANON_KEY（公开密钥）配置于代码文件顶部。

6. 常见排查问题 (FAQ)

Q1: 为什么授权后返回页面提示未绑定？

答：通常是因为域名未包含在 Supabase 的 Redirect URLs 白名单中，或者登录代码中未显式指定正确的 redirectTo 路径。

Q2: 能否在前端暴露 service_role 密钥？

答：绝对不能。service_role 密钥具备越过 RLS 规则的最高管理员权限，写在前端 JS 中会导致数据库容易被恶意攻击或清空。前端只需使用 anon 密钥。
